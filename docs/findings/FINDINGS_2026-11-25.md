## F6 (T3): annualized_yield_pct counts intrinsic value on ITM calls

- gates.py:282-286 computes yield from the full bid over the basis. On an ITM call most of
  the bid is intrinsic, so the yield gate never binds and the yield tiebreak (cc_scan.py:216)
  prefers the deepest eligible ITM strike when OI ties (tests/test_itm_cc.py: spot 10.50,
  FLAT OI, 8.00 call, "yield" 573.5714%). Not a money hazard (the call is covered); a
  reporting and ranking property for the D28 S1 decision.

- forgetrader_state.py:837 prints `wrote fresh FLAT state -> /home/forge/forgetrader-b/state.json`.
  Pasted back into a shell, `... state -> /home/.../state.json` is a `>` redirect onto live

  CLI line is a literal. tests/test_recovery_drill.py pins the line as it is today. Money
  hazard: yes (state truncation), operator-path only; `--init` runs only in a recovery. The
  drill doc warns before step 5b.
